# Стратегія та інформаційна архітектура

## 1. Цілі та метрики

**Бізнесові цілі:**
- Зростання кількості онлайн-записів через Altegio-посилання (вимірюється власником через саму Altegio-статистику, сайт лише постачає трафік).
- Зростання органічного (нерекламного) трафіку з Google за рахунок локального SEO — зараз практично нульового.
- Зменшення кількості "холодних" дзвінків з базовими питаннями (години, чи стрижуть дітей, умови сертифіката) за рахунок FAQ.

**Метрики успіху сайту (проксі, бо власного бекенду/аналітики немає):**
- Клік по будь-якій кнопці "Онлайн запис" — головна конверсійна дія.
- Клік по кнопці сертифіката (Instagram).
- Наявність сайту в Google Search Console з індексованими сторінками (зараз — 0 керованої видимості через відсутність `sitemap.xml`/meta).
- Час до першого видимого CTA на мобільному — вже ~0 (у першому екрані), тримати цей показник.

## 2. Карта сайту — рішення: **лишаємось single-page**

Підтверджено в `DECISIONS.md` (#4). Причина коротко: контенту рівно стільки, скільки поміщається в one-pager без втрати сканованості; дроблення зруйнувало б наявні зовнішні посилання (Google Business Profile, Instagram bio, вже надіслані клієнтам).

**Що лишається секцією на головній (як зараз):** Hero, Про нас, Статистика, Майстри, Послуги (короткий огляд), Сертифікат, Галерея, Відгуки, Контакти/Footer.

**Що додається новим (у межах тієї ж single-page структури, не нова сторінка):**
- **FAQ-секція** — перед Footer. 5–6 реальних питань з дослідження (див. `04-design-system.md` за компонент), заповнена реальними відповідями власника.
- **Явний блок "Дитяча стрижка"** — маленька додаткова картка в короткому гріді послуг (не нова секція, а один новий `svc-tile`), щоб закрити Persona "Марія" без розгортання акордеону.

**Що НЕ додається (свідомо):**
- Окрема сторінка "Про майстра" — 8 акордеонів на головній вже дають досить деталей; окрема сторінка на кожного означає 8 нових URL для одностраничного GitHub Pages сайту без роутингу — непропорційна складність.
- 404-сторінка — GitHub Pages вже показує свою дефолтну 404 для непроєктного домену; кастомна 404 для single-page сайту з одним реальним URL — низький пріоритет, відкладено.
- Політика конфіденційності — сайт не збирає персональні дані (немає форм, немає cookies крім Google Fonts), тому юридична потреба мінімальна; коротка примітка додається у footer замість окремої сторінки.

## 3. Структура головної посекційно (мета кожної секції)

| Секція | Мета | Чому саме тут за порядком |
|---|---|---|
| Hero | Ідентифікація за 5с + головний CTA | Перше, що бачить 100% відвідувачів |
| Про нас | Емоційний контекст, тон бренду | Одразу після hero — поки увага висока, до "сухих" фактів |
| Статистика | Швидкий соціальний доказ (8 майстрів, 4.9, 2023, години) | Місток між емоцією і функціональним вибором майстра |
| Майстри | Основна конверсійна дія — вибір і запис до конкретної людини | Найважливіший функціональний блок, тому одразу після контексту |
| Послуги (огляд + дитяча) | Швидка орієнтація по цінах для тих, хто ще не обрав майстра | Одразу після майстрів — паралельний шлях для цінового порівняння |
| Сертифікат | Друга ціль конверсії (подарунок) | Після основного шляху запису, не заважає йому |
| Галерея | Візуальне підтвердження якості/атмосфери | Підкріплення довіри перед фінальним рейтингом |
| Відгуки | Фінальний соціальний доказ | Перед контактами — "останній поштовх" |
| **FAQ (нове)** | Зняти залишкові заперечення | Прямо перед контактами — логічне місце для "ще є питання?" |
| Контакти/Footer | Довідкова інформація, повторний CTA | Завжди в кінці — стандарт, який не варто ламати |

## 4. Флоу запису — **лишається зовнішнім (Altegio)**

```
[Клієнт на сайті]
   │
   ├─ Клік "Онлайн запис" (nav / hero / footer) ─────► Altegio: загальне меню компанії
   │
   └─ Клік "Онлайн запис" під конкретним майстром ───► Altegio: сторінка вибору послуги
                                                          для ЦЬОГО майстра (deep-link)
                                                              │
                                                              ▼
                                                     [Далі — поза межами нашого сайту,
                                                      керує Altegio: послуга → дата/час →
                                                      контакти → підтвердження]
```

**Стани на нашій стороні (те, чим ми реально керуємо):**
- **Default:** кнопка видима, з чітким лейблом "Онлайн запис".
- **Hover/Focus:** легкий підйом + зміна прозорості (вже реалізовано); **Focus** — буде додано видимий `outline` (Етап 5, п. A3 аудиту).
- **Клік:** `target="_blank" rel="noopener"` — відкриває новий таб, не втрачає контекст поточної сторінки (вже реалізовано коректно).
- **Немає стану "завантаження" чи "помилка"** — бо дії немає, лише навігація по посиланню; це коректно для зовнішнього booking, вигадувати проміжний "мок-степер" (як пропонує типовий бриф) означало б додати фальшивий UI-шар, який нічого не робить і сповільнює реальний флоу — прямо суперечить меті "менше кліків до запису".

```

[Записатися онлайн]  [Обрати майстра]  [★★★★★ 4,9/5 на Google відгуках]
```

### Картка майстра — обидва брейкпоінти (гнучка сітка, сама картка не змінюється)
```
┌─────────────────┐
│   [фото 3:4]     │
├─────────────────┤
│ АРТ-ДИРЕКТОР     │
│ Денис            │
│ Багато років...   │ (обрізано до 3 рядків)
│ ─────────────    │
│ Послуги та ціни › │ ← акордеон
│ [Онлайн запис]    │
└─────────────────┘
```

### Нова FAQ-секція — вайрфрейм
```
ЧАСТІ ПИТАННЯ
```

Ці вайрфрейми напряму реалізуються в Етапі 5 без додаткового погодження.
