# Інвентаризація поточного сайту

**Дата аудиту:** 2026-09-28
**Об'єкт:** Bless Cuts Barbershop, Львів — живий сайт реального бізнесу
**Джерело:** `index.html`, single-page, задеплоєний на GitHub Pages (`Nazya-Why/bless-cuts-barbershop`)

## Стек

- Чистий HTML/CSS/JS, без білд-кроку, без залежностей.
- Один файл `index.html` (~39 KB) з інлайн `<style>` і інлайн `<script>`.
- Шрифт: Google Fonts Inter (400–800).
- Іконки: жодних SVG-іконок, лише текстові символи (★, ›) та emoji-подібні unicode-глліфи.
- Зображення: локальні JPG/PNG у `/images`, без `srcset`, без AVIF/WebP, без явних `width`/`height` атрибутів (є лише `loading="lazy"` на більшості).
- Бронювання: не власна форма, а глибокі посилання на зовнішню систему **Alteg.io** (по одному на кожного майстра + загальне меню).
- Хостинг: GitHub Pages, HTTPS примусовий, `Cache-Control: max-age=600` на edge (Fastly).

## Карта сторінки (single-page, якорі)

1. `#top` — nav (sticky, glass, бургер-меню на мобільному)
2. Hero (повноекранний, фото-фон, заголовок + 2 CTA + рейтинг-бейдж)
3. `#about` — "Про нас" (фото + текст)
4. Stats strip (4 картки: майстрів, рейтинг, рік заснування, години)
5. `#team` — сітка з 8 карток майстрів, кожна з акордеоном цін і кнопкою запису
6. `#services` — короткий грід орієнтовних цін ("від X ₴")
7. Gift-сертифікат — банер-фото + текст + CTA в Instagram
8. `#gallery` — сітка 12 фото (lightbox відсутній, відкриває фото в новій вкладці)
9. `#reviews` — рейтинг 4.9/5 + посилання на Google Maps
10. `#contacts` (footer) — лого, контакти, адреса, години, копірайт

## Технічні спостереження (без оцінки — сама фактура)

- Немає `<meta name="description">`, немає Open Graph, немає `schema.org`, немає `sitemap.xml`, немає `robots.txt`, немає `favicon` у форматі, що покриває всі розміри (є лише 16/32/apple-touch).
- Немає `alt`, що описує суть фото по-різному — частина `alt` є, частина відсутня (перевірити точково в аудиті).
- Uk-локаль вказана (`lang="uk"`), другої мови немає.
- Increased-motion: `.reveal`/`.reveal-group` коректно обгорнуті в `@media (prefers-reduced-motion: no-preference)`, є `setTimeout`-запобіжник на 3с, щоб контент не завис невидимим — це вже виправлена цього сеансу проблема.
- Візуальна мова: "Liquid Glass" — напівпрозорі затемнені панелі з `backdrop-filter: blur()`, великі скруглення, чорно-біло-графітова палітра, типографіка Inter. Ця концепція вже затверджена реальним власником бізнесу через десятки ітерацій цього сеансу — не переробляти з нуля, лише систематизувати.
- Немає окремих сторінок — усе на одному URL, навігація через `#anchor` + `scrollIntoView`.
- Форма запису відсутня в принципі: клієнт свідомо використовує зовнішній Alteg.io замість власної форми — це вже робочий, дійсний флоу, не заглушка.
